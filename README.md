# QoffeeAutomat

**QoffeeAutomat** is a PC agent (Windows first, Linux later) and a matching Home Assistant custom integration (`qoffeeautomat`) that lets Home Assistant monitor a PC and run user-defined commands and PowerShell scripts on it over the bidirectional **QoffeeLink** WebSocket protocol.

> [!NOTE]
> The project is currently being rebuilt from the ground up. The original prototype remains preserved at the `prototype-v0` Git tag and as reference material in [`docs/prototype/`](./docs/prototype/).
